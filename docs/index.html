04 // everything it does

Plan

the companion
  • Search your knowledge — semantic search over ~2,747 techniques, one keystroke away.
  • Compose attack paths — describe a target, get an ordered recon→privesc walkthrough, grounded in real commands.
  • Run engagements — a live checklist that remembers your steps, evidence and creds.
  • Draft reports — grounded write-ups (OSCP / CPTS / bug-bounty formats) built from what you actually did.
  • Ask the assistant — a chat that knows where you are and cites real techniques.

Execute

gated · human-approved
  • Run commands live — streamed from an isolated lab or a scope-locked real target.
  • Guided loop — the AI proposes the next command; you approve each one.
  • Second opinion — any generated command gets one honestly-labelled alternative and a which-is-better verdict, on tap. Advice only — it never auto-selects.
  • Kill-chain map — watch the attack path light up as it runs.
  • Real shells — a persistent :kali shell and a full :terminal (vim, msfconsole, evil-winrm).
  • HTTP repeater — compose, send, replay and diff web requests.
  • Web-vuln testers — single-packet race conditions, request smuggling, cache poisoning, a JWT/OAuth token workbench, a nuclei template scanner and a positional intruder — safe detect, gated confirm.
  • CVE lookup — :exploits maps a service + version to public exploits.

Go deeper

the hard stuff
  • Active Directory — load BloodHound, see the route to Domain Admin, and let the AI walk it live over WinRM — Kerberoast, DCSync, AD CS (ESC1–8) and delegation abuse.
  • Cloud attack — map a cloud account's IAM to the path to admin, and chain a web SSRF into cloud credentials via the metadata service.
  • Cross-domain kill-chain — stitch web → cloud → on-prem into one route to the objective.
  • C2 & tunnels — Sliver implants, DNS tunneling, chisel/ligolo pivoting — all behind the gates.
  • Tool arsenal — 155 tools with ready-to-run commands, target already filled in.
  • Code scan — static AppSec + AI code-audit (incl. Web3), across many languages.

You hold the leash

manual → full
  • Run it three ways — approve every command, auto-run the safe stuff, or go fully autonomous inside rules you set.
  • Autonomy is off by default — two deliberate switches before anything self-runs, and a kill-switch halts it mid-run.
  • Dangerous stays human — exploitation, the repeater and risky commands never auto-fire; anything new is treated as off-limits.
  • Full mode is leashed — it acts only inside your written Rules of Engagement and a fire budget, and every action is logged.
  • Isolated lab or scoped target — practice egress-free, or bind a real engagement to an exact scope.
  • Purple-team view — for every action, see what a defender would see (telemetry, ATT&CK, the alert that fires).

◆ Local-first

Runs entirely on your machine — no cloud, no account, nothing leaving your box. Use a fully local LLM or a frontier one. The repo ships code only; the knowledge base builds locally, so a fresh clone starts empty.

⚠ Authorized use only

A real offensive tool — with C2, evasion and a live Windows/AD path. Run it only against systems you own or have explicit written permission to test. In engagement mode, your approval is the only thing bounding where a command goes.
