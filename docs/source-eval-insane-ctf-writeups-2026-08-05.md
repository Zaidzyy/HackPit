## No silent caps

- Nothing was sampled, truncated or top-N'd in the SEGMENTATION or the VERDICT pass:
  all 198 sections and all 97 documents carry a verdict.
- Full-text lifts into context were bounded ON PURPOSE and are listed here:
  docs #1 (bcrypt windows), #52, #60, #61, #65, #67 read in full; #50/#51 read in part
  (first ~270 lines); the other 89 documents were judged from measured signal counts
  (concept lexicon x KB hit counts) plus their first ~12 lines, NOT from a full read.
- GitHub repos offered by the file: 0 of 5 allowed were followed. Every candidate had
  full inline source + PoC + evidence, so the 'inline text too thin' precondition never
  fired. Not-followed includes Abdelkad3r/VuwCTF-2026.
